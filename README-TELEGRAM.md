# تشغيل VidReward داخل Telegram

## ما أُضيف

- تحميل Telegram WebApp SDK وقراءة الاسم والصورة ومعرّف المستخدم من جلسة Mini App.
- إظهار صورة المستخدم في دائرة بجوار زر البحث، وترحيب باسمه الأول حتى خمسة أحرف.
- إخفاء بطاقات ومشغلات YouTube داخل Telegram وإظهار زر يفتح الفيديو في صفحة مشاهدة منفصلة `/watch`.
- تضمين الفيديو مباشرة في صفحة المتصفح، مع اسم المستخدم ومعرّفه للعرض.
- ربط Telegram ID بوسم Memo/Tag في الفاتورة، وإظهاره ضمن تفاصيل الفاتورة.

## الإعداد

1. انشر الموقع على عنوان HTTPS عام.
2. عيّن عنوان الموقع المنشور كعنوان Mini App في إعدادات بوت Telegram، واضبط النطاق المسموح به لدى BotFather.
3. افتح التطبيق من زر الـ Mini App في Telegram. يفتح زر المشاهدة صفحة `/watch` على نطاق الموقع نفسه.

## حدود النسخة الحالية

- الاسم والصورة والمعرّف في صفحة المتصفح بيانات عرض أُرسلت في جزء الرابط `#`؛ لا تستخدمها لإثبات الهوية أو قبول عمليات مالية.
- يتطلب التحقق الموثوق من المستخدم التحقق خادميًا من `Telegram.WebApp.initData` باستخدام رمز البوت المخزّن على الخادم. لا تضع رمز البوت في ملفات الواجهة.
- رصيد المشاهدات والفواتير وعمليات الإيداع في المشروع الحالي تجريبية ومحلية؛ لا يوجد API أو قاعدة بيانات لتأكيد مشاهدة YouTube أو مزامنة الأرباح بين المتصفح وTelegram.
- قد لا تسمح بعض فيديوهات YouTube بالتضمين. عندها يمكن للمستخدم فتحها مباشرةً على YouTube من صفحة المشاهدة.
